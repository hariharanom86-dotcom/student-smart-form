# 🎓 Student Smart Form

A simple and interactive Student Registration Form built using **HTML, CSS, and JavaScript**. This project allows users to enter student details, dynamically display them in a table, and delete individual student records.

## 🌐 Live Demo

[Click here to view Student Smart Form](https://hariharanom86-dotcom.github.io/student-smart-form/)

## 📌 About The Project

The **Student Smart Form** is a beginner-friendly frontend web development project designed to manage student registration details through a simple and user-friendly interface.

Users can enter student information such as Name, Age, Gender, Course, and Email. When the Save button is clicked, the submitted details are dynamically added to a table below the form.

Each student record includes a Delete button, allowing users to remove a specific student's entire row from the table.

This project demonstrates basic form handling, DOM manipulation, event handling, and dynamic HTML element creation using JavaScript.

## ✨ Features

- **Student Registration:** Enter student details through a simple registration form.
- **Dynamic Table Display:** Automatically displays submitted student information in rows and columns.
- **Form Validation:** Checks whether Name, Age, and Email fields are filled before submission
